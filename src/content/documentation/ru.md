# Кастомные темы 16Launcher

Кастомные темы позволяют изменять внешний вид интерфейса 16Launcher с помощью CSS. Тема может изменять цвета, фон, скругления, границы, акцентные элементы и другие визуальные свойства интерфейса.

В этой статье описано, как устанавливать, создавать, настраивать, удалять и распространять темы для 16Launcher.

## 1. Что такое тема

Тема 16Launcher представляет собой отдельную папку с двумя обязательными файлами:

| Файл         | Назначение                                          |
| ------------ | --------------------------------------------------- |
| `theme.json` | Метаданные темы: название, автор, описание и версия |
| `style.css`  | CSS-стили, изменяющие внешний вид интерфейса        |

Дополнительно в папке темы можно размещать изображения, шрифты и другие ресурсы, необходимые для оформления.

Пример структуры темы:

```text
my-theme/
├── theme.json
├── style.css
├── background.png
└── fonts/
    └── MyFont.woff2
```

Файлы, дополнительные ресурсы и структура внутри папки могут отличаться в зависимости от назначения темы. Однако `theme.json` и `style.css` должны присутствовать обязательно.

### Как работает кастомная тема

Кастомная тема не заменяет интерфейс 16Launcher целиком. Она применяется поверх стандартного оформления приложения и изменяет его с помощью CSS-правил.

Например, тема может:

* изменить основной акцентный цвет;
* изменить цвет и прозрачность панелей;
* настроить внешний вид кнопок;
* изменить скругление элементов;
* изменить оформление активных элементов боковой панели;
* добавить фоновые изображения;
* подключить пользовательские шрифты.

Это позволяет создавать как небольшие визуальные изменения, так и полностью переработанные цветовые схемы интерфейса.

---

## 2. Расположение тем

После установки 16Launcher темы хранятся в отдельном каталоге `themes`.

Расположение каталога зависит от операционной системы.

| Операционная система | Каталог тем                                        |
| -------------------- | -------------------------------------------------- |
| Windows              | `%APPDATA%\16Launcher\themes\`                     |
| Linux                | `~/.local/share/16Launcher/themes/`                |
| macOS                | `~/Library/Application Support/16Launcher/themes/` |

### Windows

На Windows каталог обычно находится по следующему пути:

```text
C:\Users\<ИмяПользователя>\AppData\Roaming\16Launcher\themes\
```

Вместо `<ИмяПользователя>` используется имя текущей учетной записи Windows.

### Структура каталога

Каждая тема должна находиться в отдельной папке:

```text
themes/
├── example-theme/
│   ├── theme.json
│   └── style.css
│
└── my-cool-theme/
    ├── theme.json
    ├── style.css
    └── background.png
```

Не следует помещать несколько тем в одну папку. Каждая тема должна иметь собственный каталог.

### Как открыть каталог тем

Каталог тем можно открыть непосредственно из интерфейса лаунчера:

**Настройки → Лаунчер → Кастомная тема → Открыть папку тем**

Этот способ рекомендуется использовать, если необходимо вручную установить, изменить или удалить тему.

---

## 3. Как включить тему

После установки тема появляется в списке доступных тем.

Чтобы включить тему:

1. Откройте **Настройки**.
2. Перейдите во вкладку **Лаунчер**.
3. Найдите раздел **Кастомизация**.
4. Откройте пункт **Кастомная тема**.
5. Выберите нужную тему.

Тема применяется непосредственно после выбора.

Чтобы вернуть стандартное оформление 16Launcher, выберите **Стандартная**.

Выбранная тема сохраняется в настройках лаунчера, поэтому повторно выбирать ее после каждого запуска приложения не требуется.

---

## 4. Установка темы

Установить тему можно несколькими способами.

### 4.1. Импорт ZIP-архива

Импорт ZIP является наиболее простым способом установки готовой темы.

Порядок установки:

1. Откройте настройки кастомных тем.
2. Нажмите **Импорт ZIP**.
3. Выберите ZIP-архив с темой.
4. Дождитесь завершения импорта.
5. Выберите установленную тему в списке.

После успешного импорта тема появляется в каталоге `themes` и становится доступной в списке тем.

### Требования к ZIP-архиву

В архиве должны присутствовать:

```text
theme.json
style.css
```

Файлы могут находиться непосредственно в корне архива:

```text
ocean-mint.zip
├── theme.json
└── style.css
```

Также они могут находиться внутри одной общей папки:

```text
ocean-mint.zip
└── ocean-mint/
    ├── theme.json
    └── style.css
```

Оба варианта поддерживаются.

При наличии дополнительных ресурсов структура может выглядеть следующим образом:

```text
ocean-mint.zip
└── ocean-mint/
    ├── theme.json
    ├── style.css
    ├── background.png
    └── fonts/
        └── MyFont.woff2
```

Для имени ZIP-архива рекомендуется использовать латинские символы, цифры, дефисы и символы подчеркивания.

Например:

```text
ocean-mint.zip
dark-glass.zip
baza-emerald.zip
```

### Определение ID при импорте

При импорте ZIP идентификатор темы формируется на основе имени ZIP-файла с очисткой недопустимых символов.

Например:

```text
Ocean Mint.zip
```

может получить ID:

```text
ocean-mint
```

Поэтому рекомендуется заранее использовать корректное имя архива.

---

## 5. Установка темы вручную

Тему также можно установить без использования импорта ZIP.

Для этого:

1. Создайте отдельную папку для темы.
2. Добавьте в нее `theme.json` и `style.css`.
3. При необходимости добавьте изображения, шрифты и другие ресурсы.
4. Скопируйте папку в каталог `themes`.
5. Откройте настройки 16Launcher.
6. Перейдите в раздел кастомных тем.
7. Выберите установленную тему.

Например:

```text
themes/
└── ocean-mint/
    ├── theme.json
    ├── style.css
    └── background.png
```

Если список тем уже был открыт во время копирования файлов, может потребоваться повторно открыть вкладку **Лаунчер** или перезапустить 16Launcher.

---

## 6. Создание темы из 16Launcher

16Launcher позволяет создать новую тему непосредственно из настроек.

Порядок действий:

1. Откройте **Настройки → Лаунчер → Кастомная тема**.
2. Нажмите **Создать тему**.
3. Укажите название темы.
4. 16Launcher создаст каталог темы.
5. В каталоге будут созданы стандартные `theme.json` и `style.css`.
6. Нажмите **Редактировать CSS**, чтобы открыть `style.css` во внешнем редакторе.
7. Внесите необходимые изменения.
8. Сохраните файл.

После изменения CSS переключите тему или повторно выберите ее, чтобы применить изменения.

### Обновление темы после изменения CSS

В текущей версии 16Launcher нет автоматического отслеживания изменений `style.css` в реальном времени.

Поэтому после редактирования файла необходимо:

* переключиться на другую тему и обратно;
* либо перезапустить лаунчер.

Это особенно важно при разработке темы, поскольку сохранение файла в текстовом редакторе само по себе не гарантирует немедленного обновления интерфейса.

## 7. Идентификатор и отображаемое имя темы

У каждой темы есть два разных имени:

1. **ID темы** — техническое имя каталога;
2. **Название темы** — имя, отображаемое пользователю.

Эти значения используются для разных целей и не должны рассматриваться как одно и то же.

### 7.1. ID темы

ID — это имя папки темы на диске.

Например:

```text
ocean-mint/
```

где `ocean-mint` является ID темы.

Рекомендуемые правила:

* использовать латинские буквы;
* использовать цифры при необходимости;
* использовать `-` и `_`;
* не использовать пробелы;
* не использовать специальные символы;
* предпочтительно использовать нижний регистр;
* использовать короткое и понятное название.

Рекомендуемые варианты:

```text
ocean-mint
dark-glass
baza-emerald
my-theme
theme_01
```

Нежелательные варианты:

```text
Моя тема!!!
theme 1
Cool Theme (final)
тема-новая
```

При создании темы через кнопку **Создать тему** 16Launcher автоматически формирует ID на основе указанного названия.

Например:

```text
Ocean Mint
```

преобразуется в:

```text
ocean-mint
```

При импорте ZIP идентификатор формируется на основе имени ZIP-архива.

### 7.2. Отображаемое название

Отображаемое название задается в поле `name` файла `theme.json`.

В отличие от ID, это имя предназначено непосредственно для пользователя.

В нем можно использовать:

* кириллицу;
* пробелы;
* заглавные буквы;
* специальные символы;
* другие символы, поддерживаемые UTF-8.

Например:

```json
{
  "name": "Изумрудный океан",
  "author": "BAZA",
  "description": "Зелёно-бирюзовая тема для 16Launcher",
  "version": "1.0"
}
```

В этом случае:

* ID темы может быть `ocean-mint`;
* отображаемое название — `Изумрудный океан`.

## 8. Формат `theme.json`

Файл `theme.json` содержит метаданные темы.

Минимальный пример:

```json
{
  "name": "Моя тема",
  "author": "Ваше имя",
  "description": "Краткое описание темы",
  "version": "1.0"
}
```

Поддерживаемые поля:

| Поле          | Назначение                 |
| ------------- | -------------------------- |
| `name`        | Название темы в интерфейсе |
| `author`      | Автор темы                 |
| `description` | Краткое описание           |
| `version`     | Версия темы                |

Все поля являются необязательными. Однако рекомендуется указывать как минимум `name`, `author`, `description` и `version`, особенно если тема предназначена для распространения.

Если `name` не указан или пуст, в интерфейсе может использоваться имя каталога темы.

### Версия темы

Для версии рекомендуется использовать понятный формат:

```text
1.0
```

или:

```text
1.2.0
```

При значительных изменениях темы версию рекомендуется увеличивать, чтобы пользователям было проще отличать новые версии от предыдущих.

### Кодировка файла

`theme.json` должен быть сохранен в кодировке UTF-8.

При использовании кириллицы это особенно важно. Неправильная кодировка файла может привести к некорректному отображению названия, автора или описания.

## 9. Формат `style.css`

Основная настройка внешнего вида темы выполняется в файле `style.css`.

Это обычный CSS-файл, поэтому для создания темы можно использовать стандартные CSS-свойства, селекторы, переменные, градиенты, изображения, шрифты и другие возможности CSS, доступные в интерфейсе 16Launcher.

Простейший пример:

```css
:root {
  --accent-color: #10b981;
}

.glass-panel {
  background: rgba(6, 40, 30, 0.75) !important;
  border-color: rgba(16, 185, 129, 0.35) !important;
}

.accent-bg {
  background: linear-gradient(135deg, #34d399, #059669) !important;
}

.interactive-press {
  border-radius: 16px !important;
}

.sidebar-icon-active {
  color: #6ee7b7 !important;
}
```

### Использование `!important`

Стандартные стили 16Launcher могут иметь более высокий приоритет, чем правила пользовательской темы.

В таких случаях может потребоваться `!important`.

Например:

```css
.glass-panel {
  background: rgba(6, 40, 30, 0.75) !important;
}
```

Не следует использовать `!important` абсолютно для всех свойств без необходимости. Сначала рекомендуется проверить, применяется ли обычное CSS-правило.

---

## 10. Основные селекторы 16Launcher

В темах можно использовать следующие классы и CSS-переменные.

| Селектор               | Назначение                                      |
| ---------------------- | ----------------------------------------------- |
| `.glass-panel`         | Основные стеклянные панели интерфейса           |
| `.glass-chip`          | Небольшие чипы и бейджи                         |
| `.interactive-press`   | Кликабельные элементы и кнопки                  |
| `.accent-bg`           | Акцентный фон, включая некоторые кнопки         |
| `.accent-border`       | Акцентная граница                               |
| `.accent-chip`         | Акцентные чипы                                  |
| `.sidebar-icon-active` | Активная иконка боковой панели                  |
| `:root`                | Корневой элемент для определения CSS-переменных |
| `--accent-color`       | Основной акцентный цвет                         |

Набор доступных классов может изменяться вместе с развитием 16Launcher. Поэтому при создании сложной темы рекомендуется проверять ее работу после обновления лаунчера.

---

## 11. Использование изображений

В тему можно добавить собственные изображения.

Например:

```text
ocean-mint/
├── theme.json
├── style.css
└── background.png
```

После этого изображение можно подключить из `style.css`:

```css
.glass-panel {
  background-image: url(background.png) !important;
  background-size: cover !important;
}
```

Путь к ресурсу должен быть относительным.

Если изображение находится во вложенной папке:

```text
ocean-mint/
├── theme.json
├── style.css
└── images/
    └── background.png
```

используйте:

```css
.glass-panel {
  background-image: url(images/background.png) !important;
}
```

16Launcher обрабатывает относительные `url(...)` и преобразует их в рабочие пути к ресурсам темы.

Для локальных файлов темы не следует использовать абсолютные пути конкретного компьютера, например:

```text
C:\Users\User\Desktop\background.png
```

Такие пути не будут работать после передачи темы другому пользователю.

---

## 12. Использование пользовательских шрифтов

В папку темы можно добавить собственные файлы шрифтов.

Например:

```text
ocean-mint/
├── theme.json
├── style.css
└── fonts/
    └── MyFont.woff2
```

Подключить шрифт можно с помощью `@font-face`:

```css
@font-face {
  font-family: "MyFont";
  src: url(fonts/MyFont.woff2);
}

body {
  font-family: "MyFont", sans-serif;
}
```

Для распространения темы рекомендуется убедиться, что лицензия используемого шрифта разрешает его распространение вместе с другими файлами.

---

## 13. Рекомендации по созданию тем

При разработке темы рекомендуется придерживаться следующих правил:

### Используйте CSS-переменные

Если тема использует несколько элементов одного цвета, удобно определить цвет один раз:

```css
:root {
  --accent-color: #10b981;
}
```

Это упрощает дальнейшее изменение цветовой схемы.

### Не изменяйте системные файлы 16Launcher

Все изменения должны находиться внутри собственной папки темы.

Не рекомендуется изменять файлы самого приложения для создания визуального оформления.

### Используйте относительные пути

Для изображений и шрифтов используйте:

```css
url(images/background.png)
```

а не пути, привязанные к конкретному компьютеру.

### Проверяйте тему после установки

Перед распространением рекомендуется проверить:

* отображение всех панелей;
* кнопки;
* активные элементы;
* фоновые изображения;
* пользовательские шрифты;
* работу темы после повторного запуска;
* корректность ZIP-архива.

---

## 14. Как поделиться темой

Для распространения тему рекомендуется упаковать в ZIP-архив.

Порядок действий:

1. Откройте каталог темы.
2. Убедитесь, что присутствуют `theme.json` и `style.css`.
3. Проверьте дополнительные изображения и шрифты.
4. Создайте ZIP-архив.
5. Передайте архив другим пользователям.

Можно архивировать непосредственно папку темы:

```text
ocean-mint.zip
└── ocean-mint/
    ├── theme.json
    ├── style.css
    └── background.png
```

Также допустим архив, содержащий файлы темы непосредственно в корне:

```text
ocean-mint.zip
├── theme.json
└── style.css
```

В качестве имени архива рекомендуется использовать ID темы:

```text
ocean-mint.zip
```

Это упрощает идентификацию темы и позволяет корректно сформировать ее ID при импорте.

Получатель сможет установить тему через:

**Настройки → Лаунчер → Кастомная тема → Импорт ZIP**

---

## 15. Удаление темы

Удалить установленную тему можно непосредственно из интерфейса 16Launcher.

1. Откройте список кастомных тем.
2. Выберите тему.
3. Нажмите **Удалить тему**.
4. Подтвердите удаление.

Также папку темы можно удалить вручную из каталога `themes`.

### Встроенные темы

Некоторые темы, поставляемые вместе с 16Launcher, могут автоматически восстанавливаться при следующем запуске приложения.

Например, если удалить встроенную тему `example-theme`, лаунчер может повторно скопировать ее из встроенных ресурсов, если обнаружит, что соответствующей папки больше нет.

## 16. Типичные проблемы

### Тема не появляется в списке

Проверьте следующее:

* существует ли папка темы;
* присутствует ли `theme.json`;
* присутствует ли `style.css`;
* находятся ли эти файлы непосредственно в папке темы;
* корректно ли сформирован JSON;
* находится ли тема в правильном каталоге `themes`.

Правильная структура:

```text
themes/
└── my-theme/
    ├── theme.json
    └── style.css
```

### После импорта получился неправильный ID

При импорте ZIP ID формируется на основе имени архива.

Например:

```text
My Cool Theme.zip
```

может получить ID, отличающийся от ожидаемого.

Если необходимо изменить ID, переименуйте ZIP-архив и импортируйте тему повторно.

### CSS не применяется

Возможные причины:

1. Ошибка в CSS-селекторе.
2. Стандартное правило имеет более высокий приоритет.
3. Не используется `!important`, когда он необходим.
4. Тема не была повторно применена после изменения файла.
5. Изменения не были сохранены в редакторе.

После изменения `style.css` переключите тему или перезапустите 16Launcher.

### Изображение не отображается

Проверьте:

* существует ли файл;
* правильно ли указан относительный путь;
* совпадает ли регистр букв в имени файла;
* находится ли файл внутри папки темы.

Например:

```css
background-image: url(images/background.png);
```

требует наличия файла:

```text
images/background.png
```

### Тема исчезла после сброса настроек

Сброс настроек может снять выбранную тему или вернуть стандартное оформление.

При этом папка самой темы в каталоге `themes` обычно остается.

В таком случае откройте список кастомных тем и выберите тему повторно.

## 19. Быстрый старт

Создать первую тему можно за несколько минут.

### Шаг 1. Создайте тему

Откройте:

**Настройки → Лаунчер → Кастомная тема → Создать тему**

Введите, например:

```text
Моя тема
```

16Launcher создаст каталог темы и необходимые файлы.

### Шаг 2. Откройте CSS

Нажмите **Редактировать CSS**.

Откроется файл:

```text
style.css
```

### Шаг 3. Добавьте стили

Например:

```css
:root {
  --accent-color: #10b981;
}

.glass-panel {
  background: rgba(6, 40, 30, 0.75) !important;
}

.accent-bg {
  background: #10b981 !important;
}
```

Сохраните файл.

### Шаг 4. Примените изменения

Переключите тему на **Стандартная**, затем снова выберите созданную тему.

Также можно полностью перезапустить 16Launcher.

После этого изменения CSS должны примениться.

### Шаг 5. Подготовьте тему к распространению

Когда оформление будет готово, откройте папку темы и упакуйте ее в ZIP-архив.

Рекомендуемый вариант:

```text
my-theme.zip
└── my-theme/
    ├── theme.json
    └── style.css
```

Полученный архив можно передать другим пользователям. Для установки им достаточно использовать **Импорт ZIP**.
