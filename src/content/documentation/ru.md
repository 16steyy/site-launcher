# Темы 16Launcher

Тема — это папка с CSS-файлом, который перекрашивает интерфейс лаунчера: цвета, фон, скругления, панели, кнопки. Ниже всё, что нужно, чтобы поставить чужую тему или собрать свою.

## Быстрый старт

1. Откройте **Настройки → Лаунчер → Кастомная тема** и нажмите **Создать тему**.
2. Введите название, например `Моя тема`. Лаунчер создаст папку с `theme.json` и `style.css`.
3. Нажмите **Редактировать CSS** и вставьте:

   ```css
   :root {
     --accent-color: #10b981;
   }

   .glass-panel {
     background: rgba(6, 40, 30, 0.75) !important;
   }

   .accent-bg {
     background: #10b981 !important;
   }
   ```

4. Сохраните файл, выберите **Стандартная**, а потом снова свою тему. Изменения применятся.
5. Когда всё готово, запакуйте папку темы в ZIP и отправьте друзьям или загрузите в [каталог тем](/themes/upload).

Дальше то же самое по шагам и с подробностями.

## Из чего состоит тема

Минимум два файла:

| Файл | Что в нём |
| --- | --- |
| `theme.json` | Название, автор, описание и версия |
| `style.css` | Стили, которые меняют интерфейс |

Рядом можно положить картинки и шрифты:

```text
my-theme/
├── theme.json
├── style.css
├── background.png
└── fonts/
    └── MyFont.woff2
```

Тема не заменяет интерфейс, а ложится поверх стандартного оформления. Разметку лаунчера она не меняет: можно перекрасить панель, но нельзя переставить кнопки местами.

## Где лежат темы

| Система | Папка |
| --- | --- |
| Windows | `%APPDATA%\16Launcher\themes\` |
| Linux | `~/.local/share/16Launcher/themes/` |
| macOS | `~/Library/Application Support/16Launcher/themes/` |

Проще всего открыть папку из лаунчера: **Настройки → Лаунчер → Кастомная тема → Открыть папку тем**.

У каждой темы своя папка, файлы лежат прямо в ней:

```text
themes/
├── example-theme/
│   ├── theme.json
│   └── style.css
└── my-cool-theme/
    ├── theme.json
    ├── style.css
    └── background.png
```

Если положить `theme.json` и `style.css` прямо в `themes/` или спрятать на уровень глубже, лаунчер тему не увидит.

## Как включить тему

1. Откройте **Настройки** → вкладка **Лаунчер**.
2. В разделе **Кастомизация** откройте **Кастомная тема**.
3. Выберите тему из списка.

Тема применяется сразу и запоминается: после перезапуска выбирать её заново не нужно. Чтобы вернуть обычный вид, выберите **Стандартная**. Папка темы при этом остаётся на месте.

## Установка

### Из ZIP-архива

1. Откройте **Настройки → Лаунчер → Кастомная тема**.
2. Нажмите **Импорт ZIP** и выберите архив.
3. Выберите появившуюся тему в списке.

Лаунчер понимает оба варианта архива: файлы в корне или внутри одной папки.

```text
ocean-mint.zip              ocean-mint.zip
├── theme.json              └── ocean-mint/
└── style.css                   ├── theme.json
                                └── style.css
```

ID темы при импорте берётся из имени архива. Из `Ocean Mint.zip` получится `ocean-mint`, поэтому архив лучше сразу назвать латиницей, без пробелов.

### Вручную

Скопируйте папку темы в каталог `themes` и выберите её в настройках. Если список тем был открыт во время копирования, переключите вкладку или перезапустите лаунчер.

Ручной способ удобен, пока тема в разработке: правите файлы прямо в папке и не пересобираете архив.

## ID и название

У темы два имени, и это разные вещи.

**ID** — имя папки на диске, например `ocean-mint`. Используйте латиницу в нижнем регистре, цифры, `-` и `_`. Без пробелов и спецсимволов.

```text
ocean-mint     ✓
dark-glass     ✓
theme_01       ✓
Моя тема!!!    ✗
theme 1        ✗
```

При создании через **Создать тему** ID получается из названия (`Ocean Mint` → `ocean-mint`), при импорте — из имени ZIP.

**Название** — то, что видно в списке тем. Оно задаётся полем `name` в `theme.json`, и в нём можно писать как угодно: кириллицей, с пробелами и заглавными буквами. Папка `dark-glass` спокойно может показываться в лаунчере как «Тёмное стекло».

## theme.json

```json
{
  "name": "Изумрудный океан",
  "author": "BAZA",
  "description": "Зелёно-бирюзовая тема для 16Launcher",
  "version": "1.0.0"
}
```

| Поле | Что это |
| --- | --- |
| `name` | Название в списке тем |
| `author` | Автор |
| `description` | Короткое описание |
| `version` | Версия, например `1.0` или `1.2.0` |

Все поля необязательные. Без `name` лаунчер покажет имя папки. Если тему будут скачивать другие люди, заполните всё и повышайте `version` при заметных изменениях.

Сохраняйте файл в **UTF-8**. В другой кодировке кириллица в названии превратится в кракозябры.

## style.css

Обычный CSS. Работают переменные, градиенты, `url(...)`, `@font-face`, псевдоклассы и всё остальное, что поддерживает интерфейс лаунчера.

```css
:root {
  --accent-color: #10b981;
}

.glass-panel {
  background: rgba(6, 40, 30, 0.75) !important;
  border-color: rgba(16, 185, 129, 0.35) !important;
}

.interactive-press {
  border-radius: 16px !important;
}
```

### Когда нужен !important

У встроенных стилей лаунчера бывает более высокий приоритет, и тогда ваше правило молча проигрывает. В этом случае добавьте `!important`. Ставить его на всё подряд не стоит: сначала проверьте, работает ли правило без него. Чем меньше `!important`, тем проще потом разбираться, что откуда взялось.

### Изменения не видны сразу

Лаунчер читает `style.css` один раз, когда применяет тему, и за файлом не следит. После сохранения выберите **Стандартная** и снова свою тему или перезапустите лаунчер.

## Селекторы и переменные

| Селектор | Что меняет |
| --- | --- |
| `.glass-panel` | Основные стеклянные панели |
| `.glass-chip` | Маленькие чипы и бейджи |
| `.interactive-press` | Кнопки и другие кликабельные элементы |
| `.accent-bg` | Акцентный фон, в том числе у некоторых кнопок |
| `.accent-border` | Акцентная рамка |
| `.accent-chip` | Акцентные чипы |
| `.sidebar-icon-active` | Активная иконка в боковой панели |
| `--accent-color` | Основной акцентный цвет, задаётся в `:root` |

Начинать удобнее с `--accent-color`: одна строка, и акцент меняется по всему интерфейсу. Но не все элементы берут цвет из переменной, некоторые придётся перекрасить через классы.

Если нужного класса нет, можно взять селектор пошире, только проверьте, что он не зацепил лишнего. Набор классов меняется вместе с лаунчером, так что после обновлений сложные темы стоит перепроверять.

## Картинки и шрифты

Положите файлы в папку темы и подключайте по относительному пути:

```css
.glass-panel {
  background-image: url(images/background.png) !important;
  background-size: cover !important;
}
```

Лаунчер сам превратит `url(images/background.png)` в путь к файлу внутри темы. Абсолютные пути вроде `C:\Users\User\Desktop\background.png` сработают только у вас: на другом компьютере такого файла нет.

Шрифты подключаются через `@font-face`:

```css
@font-face {
  font-family: "MyFont";
  src: url(fonts/MyFont.woff2);
}

body {
  font-family: "MyFont", sans-serif;
}
```

Пара советов:

- Не кладите в тему фон на 20 МБ. Лаунчер от этого не станет красивее, а тему будет неудобно скачивать.
- Проверьте, что лицензия шрифта разрешает его распространять, если собираетесь делиться темой.
- Регистр в именах файлов важен: на Linux `Background.png` и `background.png` — разные файлы.

## Как поделиться темой

Запакуйте папку темы в ZIP и назовите архив так же, как ID: `ocean-mint.zip`. Тогда у получателя после **Импорт ZIP** получится тот же ID, что и у вас.

Перед отправкой уберите из архива всё лишнее: черновики, `.psd`, служебные файлы редактора.

### Публикация в каталоге

Тему можно загрузить в [каталог на сайте](/themes/upload), чтобы её нашли другие. Нужен аккаунт 16Launcher. Ограничения:

- архив до 5 МБ;
- внутри обязательно `theme.json` и `style.css`;
- разрешены `.json`, `.css`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.woff`, `.woff2`, `.ttf`, `.txt`.

После загрузки тема уходит на модерацию, обычно это занимает 1–2 дня.

## Удаление

Выберите тему в списке, нажмите **Удалить тему** и подтвердите. Или просто удалите её папку из `themes`.

Встроенные темы, например `example-theme`, лаунчер восстановит при следующем запуске, если их папки не окажется на месте.

## Если что-то не работает

### Тема не появляется в списке

- В папке темы есть и `theme.json`, и `style.css`?
- Файлы лежат прямо в папке темы, а не во вложенной?
- Папка темы находится внутри `themes`?
- `theme.json` — валидный JSON? Частая ошибка — запятая после последнего поля.

### CSS не применяется

- Файл сохранён?
- Тема переприменена после сохранения (через **Стандартная** или перезапуск)?
- Селектор точно совпадает с элементом?
- Встроенный стиль сильнее? Попробуйте `!important`.

### Картинка не отображается

Проверьте, что файл лежит внутри папки темы, путь в `url(...)` относительный, а регистр букв в имени совпадает.

### Получился не тот ID

ID берётся из имени ZIP. Переименуйте архив и импортируйте тему ещё раз.

### Тема пропала после сброса настроек

Сброс снимает выбор темы, но саму папку не трогает. Откройте список тем и выберите её снова.

## Чеклист перед публикацией

- [ ] ID папки латиницей, без пробелов: `my-theme`
- [ ] Есть `theme.json` и `style.css`
- [ ] `theme.json` в UTF-8, заполнены `name`, `author`, `description`, `version`
- [ ] Картинки и шрифты лежат внутри папки темы
- [ ] Все пути в CSS относительные
- [ ] Тема выглядит нормально на всех вкладках лаунчера, а не только на главной
- [ ] После перезапуска лаунчера тема на месте
- [ ] ZIP импортируется через **Импорт ZIP** без ошибок
- [ ] В архиве нет лишних файлов

## Примеры

С лаунчером идут две темы, с которых удобно начать:

- `example-theme` — фиолетовая демо-тема;
- `baza-emerald` — изумрудная тестовая тема.

Откройте их папки и посмотрите, как устроены файлы. Ещё больше примеров — в [каталоге тем](/themes): любую оттуда можно скачать и разобрать.
