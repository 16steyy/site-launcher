## 5. Categories of personal data processed

The Operator does not process special categories of personal data (information about racial or ethnic origin, political opinions, religious beliefs, health, or intimate life) and does not process biometric personal data within the meaning of Federal Law No. 152-FZ.

### 5.1. Platform account data

When a Platform account is registered and used, the Operator may process:

- nickname (display name);
- email address;
- password (stored in hashed form; the Operator does not store the password in plaintext);
- email verification code and confirmation status;
- unique account identifier;
- project support status (if any);
- access and refresh tokens issued by the Service.

### 5.2. Linked game identifiers

At the User’s initiative, the following may be linked to a Platform account:

- Ely.by identifier and username;
- Minecraft (Microsoft) identifier (UUID) and profile name;
- technical tokens required solely to complete the linking.

### 5.3. Data related to the Service’s online features

When online features are used, the Operator may process:

- friends list, incoming and outgoing friend requests;
- online presence information (online / offline status, last activity time);
- co-op room information: room identifier, owner, participants, role, status, invitations;
- notifications (friend requests, room invitations, system messages, achievements);
- the User’s achievements and the date they were obtained;
- usage statistics: number of game launches, total session time, first and last launch dates;
- launcher session information: session identifier, client name, platform information (operating system type reported by the runtime), launcher version, creation time, last activity confirmation time, and session end time.

### 5.4. Data processed to establish a peer-to-peer connection

To connect Users for co-op play, the Service uses signalling and, where necessary, relay servers (STUN/TURN). In that case, the following may be processed:

- signalling messages (SDP, ICE candidates);
- network addresses (including IP address) and ports needed to establish the connection;
- short-lived credentials for access to the relay server.

This information is used solely to organise the game connection and is not used by the Operator for advertising.

### 5.5. Technical and log information

When the Operator’s server infrastructure is accessed, the following may be processed automatically:

- IP address;
- date and time of the request;
- requested resource and response code;
- user-agent identifier (User-Agent);
- other technical parameters needed for availability, abuse protection, and fault diagnosis.

### 5.6. Data stored primarily on the User’s device

The following may be stored on the User’s device (in the application data directory and in local storage):

- launcher settings (game directory, allocated memory, interface language, notification settings, theme, and other preferences);
- information about game profiles, installed versions, mods, and related files;
- Microsoft / Minecraft and Ely.by game account tokens;
- Platform account tokens;
- image cache (including skins and avatars);
- game logs and crash reports generated by the Minecraft client.

The Operator does not automatically access save files, screenshots, Minecraft crash logs, or the contents of the game directory, except where the relevant feature is explicitly initiated by the User (for example, profile export or viewing screenshots in the launcher interface).

### 5.7. Data processed on the official website

When the official website is used, the Operator may additionally process:

- Platform account information during registration, sign-in, and profile use on the website;
- materials submitted to the theme store: theme name, theme file archive, stated author name, submitter account identifier, submission date, and moderation status;
- website interface language preferences stored in the browser’s local storage and (where applicable) in page URL parameters;
- website session tokens stored in the browser’s local storage.

### 5.8. Data the Operator does not collect

The Operator **does not**:

- sell personal data to third parties;
- secretly collect data for advertising profiling;
- connect third-party advertising pixels or web analytics systems in the desktop application;
- automatically send Minecraft crash reports to the Operator’s servers;
- process bank card payment details in the desktop application.

## 9. Third parties and data recipients

To provide the Service, the Operator and/or the User interact with the following categories of third parties. Transfer or other interaction takes place only to the extent needed for the relevant feature.

### 9.1. Authentication and game service providers

**Microsoft Corporation, Xbox, and Minecraft services (Mojang)**  
Used when signing in with a Microsoft / Minecraft account. Processing includes exchanging data with `login.live.com`, `user.auth.xboxlive.com`, `xsts.auth.xboxlive.com`, `api.minecraftservices.com`, and related services. The Operator does not receive the Microsoft account password. Access and refresh tokens are stored on the User’s device for subsequent game launches. Microsoft Privacy Statement: [https://privacy.microsoft.com](https://privacy.microsoft.com).

**Ely.by**  
Used when signing in via Ely.by (OAuth 2.0 and/or the Yggdrasil protocol). Processing includes exchanging data with `account.ely.by` and `authserver.ely.by`. Tokens are stored on the User’s device. The Ely.by privacy policy is published by the relevant rights holder.

### 9.2. Game content and update providers

When installing and updating the game, the Java runtime, mods, and related components, the client may contact:

- official Mojang / Microsoft resources (including `piston-meta.mojang.com` and related mirrors);
- mod loader catalogues (including Fabric, Quilt, Forge, and NeoForge metadata);
- Modrinth (`api.modrinth.com`);
- CurseForge (`api.curseforge.com` and file delivery networks);
- GitHub and the jsDelivr content delivery network — for certain service components, launcher updates, and informational materials (including the notification list and website news).

When those resources are contacted, the relevant operators independently process technical connection data (including IP address) under their own rules.

### 9.3. Operator infrastructure and peer-to-peer connection

The Operator’s server infrastructure (`api.16-launcher.ru` and related nodes) processes Platform account data and the information described in sections 5.3–5.5 and 5.7.

During co-op play, room participants may receive each other’s network addresses needed to establish a connection. If a direct connection is not possible, traffic may be relayed through a TURN server. The Operator uses this information solely to provide the connection.

### 9.4. Discord

If the Discord client is installed and running, the launcher may send activity status information to the local Discord client (for example, that the launcher is in use and information about the game session) via Discord Rich Presence. This transfer is made to the User’s device and is then processed by Discord under Discord’s rules. Discord Privacy Policy: [https://discord.com/privacy](https://discord.com/privacy).

### 9.5. Website fonts

The official website may load fonts from Google Fonts (`fonts.googleapis.com`, `fonts.gstatic.com`). In that case, the relevant operator independently processes technical connection data (including IP address) under its own rules. Google Privacy Policy: [https://policies.google.com/privacy](https://policies.google.com/privacy).

### 9.6. Public authorities

The Operator may provide personal data to authorised public authorities in the cases and manner established by the laws of the Russian Federation.
