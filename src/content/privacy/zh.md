## 5. 所处理个人数据的类别

运营者不处理特殊类别个人数据（关于种族和民族归属、政治观点、宗教信仰、健康状况及私密生活的信息），亦不处理第 152-FZ 号联邦法律意义上的生物识别个人数据。

### 5.1. 平台账户数据

在注册和使用平台账户时，运营者可能处理：

- 昵称（显示名称）；
- 电子邮箱地址；
- 密码（以转换/哈希形式存储；运营者不存储明文密码）；
- 电子邮箱验证码及确认事实相关信息；
- 账户唯一标识符；
- 项目支持状态信息（如有）；
- 服务签发的访问令牌和会话刷新令牌。

### 5.2. 关联的游戏标识符

经用户主动操作，可向平台账户绑定：

- Ely.by 标识符和用户名；
- Minecraft（Microsoft）标识符（UUID）和档案名称；
- 仅用于完成绑定所需的技术令牌。

### 5.3. 与服务网络功能相关的数据

在使用网络功能时，运营者可能处理：

- 好友列表、收到和发出的好友请求；
- 在线状态信息（“在线”/“离线”状态、最近活动时间）；
- 共同游戏房间信息：房间标识符、所有者、参与者、角色、状态、邀请；
- 通知（好友请求、房间邀请、系统消息、成就）；
- 用户成就及其获得日期；
- 使用统计：游戏启动次数、会话总时长、首次和最近启动日期；
- 启动器会话信息：会话标识符、客户端名称、平台信息（运行环境报告的操作系统类型）、启动器版本、创建时间、最近活动确认时间及会话结束时间。

### 5.4. 为建立点对点连接而处理的数据

为在共同游戏中连接用户，服务使用信令，并在必要时使用中继服务器（STUN/TURN）。此时可能处理：

- 信令消息（SDP、ICE 候选）；
- 建立连接所需的网络地址（包括 IP 地址）和端口；
- 访问中继服务器的短期凭据。

上述信息仅用于组织游戏连接，运营者不将其用于广告目的。

### 5.5. 技术与日志信息

在访问运营者服务器基础设施时，可能自动处理：

- IP 地址；
- 请求日期和时间；
- 所请求资源及响应代码信息；
- 用户代理标识符（User-Agent）；
- 为保障可用性、防止滥用和诊断故障所需的其他技术参数。

### 5.6. 主要存储在用户设备上的数据

在用户设备上（应用程序数据目录和本地存储中）可能保存：

- 启动器设置（游戏目录、分配内存、界面语言、通知参数、主题及其他偏好）；
- 游戏档案、已安装版本、模组及相关文件的信息；
- Microsoft / Minecraft 和 Ely.by 游戏账户令牌；
- 平台账户令牌；
- 图像缓存（包括皮肤和头像）；
- Minecraft 客户端生成的游戏日志和崩溃报告。

运营者不会自动访问存档文件、截图、Minecraft 崩溃日志及游戏目录内容，除非用户明确启动相应功能（例如导出档案、在启动器界面中查看截图）。

### 5.7. 在官方网站上处理的数据

在使用官方网站时，运营者可能额外处理：

- 在网站上注册、登录和使用资料时的平台账户信息；
- 提交至主题商店的材料：主题名称、主题文件压缩包、所填作者名、提交者账户标识符、提交日期及审核状态；
- 网站界面语言偏好，保存在浏览器本地存储中，并（必要时）保存在页面地址参数中；
- 保存在浏览器本地存储中的网站会话令牌。

### 5.8. 运营者不收集的数据

运营者**不进行**：

- 向第三方出售个人数据；
- 为广告画像而秘密收集数据；
- 在桌面应用程序中接入第三方广告像素或网站分析系统；
- 自动将 Minecraft 崩溃报告发送至运营者服务器；
- 在桌面应用程序中处理银行卡支付信息。

为提供服务，运营者和（或）用户与以下类别的第三方进行交互。传输或其他交互仅在相应功能所需的范围内进行。

### 9.1. 身份验证与游戏服务提供商

**Microsoft Corporation、Xbox 及 Minecraft 服务（Mojang）**  
用于通过 Microsoft / Minecraft 账户登录。处理包括与 `login.live.com`、`user.auth.xboxlive.com`、`xsts.auth.xboxlive.com`、`api.minecraftservices.com` 及相关服务交换数据。运营者不获取 Microsoft 账户密码。访问令牌和刷新令牌保存在用户设备上，用于随后启动游戏。Microsoft 隐私声明：[https://privacy.microsoft.com](https://privacy.microsoft.com)。

**Ely.by**  
用于通过 Ely.by 登录（OAuth 2.0 和（或）Yggdrasil 协议）。处理包括与 `account.ely.by` 和 `authserver.ely.by` 交换数据。令牌保存在用户设备上。Ely.by 隐私政策由其相应权利人公布。

### 9.2. 游戏内容与更新提供商

在安装和更新游戏、Java 运行环境、模组及相关组件时，客户端可能访问：

- Mojang / Microsoft 官方资源（包括 `piston-meta.mojang.com` 及相关镜像）；
- 模组加载器目录（包括 Fabric、Quilt、Forge 和 NeoForge 的元数据）；
- Modrinth（`api.modrinth.com`）；
- CurseForge（`api.curseforge.com` 及文件分发网络）；

访问上述资源时，相应运营者依据其自身规则独立处理连接的技术数据（包括 IP 地址）。

### 9.3. 运营者基础设施与点对点连接

### 9.4. Discord

若已安装并运行 Discord 客户端，启动器可通过 Discord Rich Presence 向本地 Discord 客户端传输活动状态信息（例如正在使用启动器以及游戏会话相关信息）。该传输发生在用户设备上，随后由 Discord 按其规则处理。Discord 隐私政策：[https://discord.com/privacy](https://discord.com/privacy)。

## 11. 个人数据保存期限

个人数据的处理和保存不超过实现处理目的所需的时间，除非俄罗斯联邦法律规定其他期限。

参考期限：

| 信息类别 | 保存期限 |
| --- | --- |
| 平台账户数据 | 账户存续期间；删除后——完成删除程序及履行法定义务所需的期间 |
| 会话令牌 | 直至过期、退出账户或删除账户 |
| 好友、房间、通知和成就信息 | 账户存续期间，或直至用户删除相应对象 |
| 启动统计 | 账户存续期间 |
| 启动器会话信息 | 会话活动期间及其结束后为保障安全所需的有限期间 |

| 服务器基础设施访问日志 | 保障安全和诊断所需期间，之后销毁或匿名化 |
| 电子邮箱验证码 | 验证码的短暂有效期内 |
| STUN/TURN 凭据 | 以分钟计的短暂有效期内 |
| 用户设备上的本地数据 | 直至用户删除或卸载应用程序 |

保存期限届满后，个人数据将被销毁或匿名化，法律另有规定的除外。
