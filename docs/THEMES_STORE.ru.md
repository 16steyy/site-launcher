# Магазин тем 16Launcher

Кастомные темы меняют внешний вид интерфейса лаунчера: цвета, шрифты, фон и другие CSS-стили.

## Что такое тема

Тема — набор файлов в ZIP-архиве. Обязательны два файла:

| Файл | Назначение |
|------|------------|
| `theme.json` | Название, описание, версия (автор подставляется автоматически) |
| `style.css` | CSS-переопределения UI лаунчера |

Пример `theme.json`:

```json
{
  "name": "Изумрудный океан",
  "author": "BAZA",
  "description": "Зелёно-бирюзовая тема",
  "version": "1.0"
}
```

Поле `author` в архиве будет **перезаписано** вашим никнеймом из аккаунта 16Launcher.

### Допустимые файлы в ZIP

`.json`, `.css`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.woff`, `.woff2`, `.ttf`, `.txt`

Максимальный размер архива: **5 МБ**.

### Структура ZIP

Файлы могут лежать в корне архива:

```
theme.zip
  theme.json
  style.css
  preview.png
```

Или в одной подпапке:

```
theme.zip
  ocean-mint/
    theme.json
    style.css
    background.png
```

Опционально добавьте `preview.png` — он появится в каталоге на сайте после публикации.

## Как подготовить ZIP

1. Создайте папку с `theme.json` и `style.css`.
2. При необходимости добавьте изображения и шрифты.
3. Упакуйте содержимое в `.zip` (не забудьте обязательные файлы).
4. Проверьте тему локально в лаунчере: **Настройки → Темы → Импорт ZIP**.

## Как загрузить на сайте

1. Откройте [16-launcher.ru/themes](https://16-launcher.ru/themes).
2. Нажмите **«Загрузить тему»**.
3. Войдите или зарегистрируйтесь на [странице аккаунта](https://16-launcher.ru/account).
4. Укажите **название темы** и выберите ZIP-файл.
5. Нажмите **«Отправить на модерацию»**.

После отправки тема попадает на проверку. Обычно это занимает **1–2 дня**.

## Модерация

Модераторы проверяют:

- корректность архива и отсутствие опасных файлов;
- работоспособность темы в лаунчере;
- соответствие правилам (без вредоносного контента).

При одобрении тема появляется в каталоге на сайте. При отказе PR закрывается без публикации.

## Как скачать и установить

### С сайта

1. Откройте [каталог тем](https://16-launcher.ru/themes).
2. Найдите понравившуюся тему и нажмите **«Скачать»**.

### В лаунчере

1. Откройте **16Launcher**.
2. Перейдите в **Настройки → Темы**.
3. Нажмите **«Импорт ZIP»** и выберите скачанный файл.
4. Активируйте тему в списке.

## Частые ошибки

| Ошибка | Решение |
|--------|---------|
| ZIP без `theme.json` или `style.css` | Добавьте оба файла в архив |
| Файл больше 5 МБ | Уменьшите размер изображений |
| «Тема уже на модерации» | Дождитесь решения или измените название |
| «Слишком много загрузок» | Подождите час (лимит: 3 загрузки в час) |
